## 간단한 소개

가까운 노드부터 **한 겹씩 퍼져나가는** 탐색.
가중치 없는 그래프에서 **최단 거리**는 무조건 BFS. 미로 문제 대부분이 이거다.

## 개념

- Breadth-First Search
- **큐(deque)** 로 구현
- 먼저 발견한 노드가 먼저 처리되니까, 처음 도착했을 때의 거리가 곧 최단 거리

## 원리

![BFS 방문 순서](/assets/img/posts/algorithm/bfs.png){: width="480" }
_BFS - 가까운 층부터_

```text
        1             거리 0
      /   \
     2     3          거리 1
    / \     \
   4   5     6        거리 2

방문 순서 : 1 → 2 → 3 → 4 → 5 → 6
```

1. 시작 노드를 큐에 넣고 방문 표시
2. 큐에서 하나 꺼내서, 연결된 노드 중 방문 안 한 곳을 **방문 표시하고** 큐에 넣기
3. 큐가 빌 때까지 반복

> 방문 표시는 **큐에 넣을 때** 해야 한다. 꺼낼 때 하면 같은 노드가 큐에 여러 번 들어가서 메모리 초과 남.

### 2178 미로 탐색 (격자 최단 거리)

```python
from collections import deque

n, m = map(int, input().split())
maze = [input().strip() for _ in range(n)]
dist = [[0] * m for _ in range(n)]
dx = [-1, 1, 0, 0]
dy = [0, 0, -1, 1]

q = deque([(0, 0)])
dist[0][0] = 1
while q:
    x, y = q.popleft()
    for d in range(4):
        nx, ny = x + dx[d], y + dy[d]
        if 0 <= nx < n and 0 <= ny < m and maze[nx][ny] == '1' and dist[nx][ny] == 0:
            dist[nx][ny] = dist[x][y] + 1     # 거리 기록 = 방문 표시
            q.append((nx, ny))

print(dist[n - 1][m - 1])
```

### 7576 토마토 (시작점이 여러 개)

익은 토마토를 **처음에 전부 큐에 넣고** 시작하면 동시에 퍼지는 걸 표현할 수 있다.

```python
import sys
from collections import deque
input = sys.stdin.readline

m, n = map(int, input().split())
box = [list(map(int, input().split())) for _ in range(n)]
dx = [-1, 1, 0, 0]
dy = [0, 0, -1, 1]

q = deque()
for i in range(n):
    for j in range(m):
        if box[i][j] == 1:
            q.append((i, j))

while q:
    x, y = q.popleft()
    for d in range(4):
        nx, ny = x + dx[d], y + dy[d]
        if 0 <= nx < n and 0 <= ny < m and box[nx][ny] == 0:
            box[nx][ny] = box[x][y] + 1
            q.append((nx, ny))

ans = 0
for row in box:
    if 0 in row:
        print(-1)
        exit()
    ans = max(ans, max(row))
print(ans - 1)
```

## DFS vs BFS

| | DFS | BFS |
| --- | --- | --- |
| 자료구조 | 재귀 / 스택 | 큐 |
| 탐색 방식 | 깊게 먼저 | 가까운 것부터 |
| 최단 거리 | X | **O** (가중치 없을 때) |
| 주로 쓰는 곳 | 덩어리 세기, 경로 전부, 백트래킹 | 최단 거리, 최소 횟수 |

"최소 몇 번", "최단 거리" → BFS 먼저 떠올리기

## 시간복잡도 / 효율성

- 인접 리스트 **O(V + E)**, 격자 **O(N × M)**
- 재귀가 없어서 파이썬에서는 DFS보다 안전함
