## 간단한 소개

**가중치가 있는 그래프**에서 한 지점으로부터 다른 모든 지점까지의 최단 거리를 구하는 알고리즘.
가중치가 없으면 BFS로 되는데, 간선마다 비용이 다르면 다익스트라를 써야 한다.
힙 정리해둔 게 여기서 바로 쓰인다.

## 개념

- **한 출발점 → 모든 노드**까지의 최단 거리
- 간선 가중치가 **음수면 안 된다** (음수 있으면 벨만-포드)
- 아직 확정 안 된 노드 중 **가장 가까운 노드를 하나씩 확정**해 나가는 그리디 방식
- 가장 가까운 노드 찾기를 **우선순위 큐(heapq)** 로 해서 빠르게

## 원리

![다익스트라](/assets/img/posts/algorithm/dijkstra.png){: width="560" }
_1번에서 출발한 최단 경로_

```text
       2
  (1) ───▶ (2)
   │        │ 3
 6 │        ▼
   └─────▶ (3) ──1──▶ (4)

출발 : 1
```

| 단계 | 꺼낸 노드 | dist[1] | dist[2] | dist[3] | dist[4] |
| --- | --- | --- | --- | --- | --- |
| 시작 | - | 0 | ∞ | ∞ | ∞ |
| 1 | 1 (0) | 0 | 2 | 6 | ∞ |
| 2 | 2 (2) | 0 | 2 | **5** | ∞ |
| 3 | 3 (5) | 0 | 2 | 5 | 6 |
| 4 | 4 (6) | 0 | 2 | 5 | 6 |

1 → 3으로 바로 가면 6인데, 1 → 2 → 3으로 가면 5라서 갱신된다.

1. 출발 노드 거리 0, 나머지 무한대
2. 힙에서 거리가 가장 짧은 노드를 꺼낸다
3. 이미 더 짧은 거리로 처리된 노드면 무시
4. 그 노드를 거쳐서 가는 게 더 짧으면 거리를 갱신하고 힙에 넣는다
5. 힙이 빌 때까지 반복

## 코드

### 1753 최단경로

```python
import sys, heapq
input = sys.stdin.readline
INF = float('inf')

V, E = map(int, input().split())
k = int(input())
graph = [[] for _ in range(V + 1)]
for _ in range(E):
    u, v, w = map(int, input().split())
    graph[u].append((v, w))

dist = [INF] * (V + 1)
dist[k] = 0
h = [(0, k)]                     # (거리, 노드)

while h:
    d, v = heapq.heappop(h)
    if dist[v] < d:              # 이미 더 짧게 처리됨 → 무시
        continue
    for nxt, w in graph[v]:
        nd = d + w
        if nd < dist[nxt]:
            dist[nxt] = nd
            heapq.heappush(h, (nd, nxt))

out = []
for i in range(1, V + 1):
    out.append('INF' if dist[i] == INF else str(dist[i]))
print('\n'.join(out))
```

> 힙에 `(거리, 노드)` 순서로 넣어야 거리 기준으로 정렬된다. 반대로 넣었다가 틀림.
{: .prompt-warning }

`if dist[v] < d: continue` 이 줄이 없으면 같은 노드를 여러 번 처리해서 시간초과 난다.

## 시간복잡도 / 효율성

| 방법 | 시간복잡도 |
| --- | --- |
| 매번 리스트에서 최솟값 찾기 | O(V²) |
| 우선순위 큐 사용 | **O(E log V)** |

노드가 많으면(1만 이상) 무조건 힙 버전.

## 최단 경로 알고리즘 비교

| | 다익스트라 | 플로이드 워셜 | 벨만-포드 |
| --- | --- | --- | --- |
| 구하는 것 | 한 점 → 전체 | 전체 → 전체 | 한 점 → 전체 |
| 음수 간선 | X | O (음수 사이클 X) | O, 음수 사이클 탐지 |
| 시간복잡도 | O(E log V) | O(V³) | O(VE) |
