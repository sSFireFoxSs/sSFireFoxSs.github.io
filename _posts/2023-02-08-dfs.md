## 간단한 소개

한 방향으로 **끝까지 들어갔다가 막히면 돌아와서** 다른 길로 가는 탐색.
연결된 덩어리 개수 세기, 경로 찾기, 백트래킹의 기본이다.

## 개념

- Depth-First Search
- **재귀** 또는 **스택**으로 구현
- 한 번 방문한 노드는 `visited`로 표시해서 다시 안 감

## 원리

![DFS 방문 순서](/assets/img/posts/algorithm/dfs.png){: width="480" }
_DFS - 깊게 먼저_

```text
        1
      /   \
     2     3
    / \     \
   4   5     6

방문 순서 : 1 → 2 → 4 → 5 → 3 → 6
```

1. 현재 노드 방문 표시
2. 연결된 노드 중 방문 안 한 곳으로 들어감 (재귀)
3. 더 갈 곳이 없으면 이전 노드로 돌아옴

## 코드

### 재귀 DFS

```python
import sys
sys.setrecursionlimit(10 ** 6)

def dfs(v):
    visited[v] = True
    order.append(v)
    for nxt in graph[v]:
        if not visited[nxt]:
            dfs(nxt)
```

### 스택 DFS (재귀 깊이 걱정될 때)

```python
def dfs_stack(start):
    stack = [start]
    while stack:
        v = stack.pop()
        if visited[v]:
            continue
        visited[v] = True
        for nxt in reversed(graph[v]):   # 작은 번호부터 가려고 뒤집음
            if not visited[nxt]:
                stack.append(nxt)
```

### 11724 연결 요소의 개수

방문 안 한 노드에서 DFS 시작할 때마다 덩어리 +1.

```python
import sys
sys.setrecursionlimit(10 ** 6)
input = sys.stdin.readline

n, m = map(int, input().split())
graph = [[] for _ in range(n + 1)]
for _ in range(m):
    a, b = map(int, input().split())
    graph[a].append(b)
    graph[b].append(a)

visited = [False] * (n + 1)

def dfs(v):
    visited[v] = True
    for nxt in graph[v]:
        if not visited[nxt]:
            dfs(nxt)

cnt = 0
for i in range(1, n + 1):
    if not visited[i]:
        dfs(i)
        cnt += 1
print(cnt)
```

### 2667 단지번호붙이기 (격자 DFS)

```python
import sys
sys.setrecursionlimit(10 ** 6)

n = int(input())
board = [list(map(int, input().strip())) for _ in range(n)]
dx = [-1, 1, 0, 0]
dy = [0, 0, -1, 1]

def dfs(x, y):
    board[x][y] = 0          # 방문 표시 (0으로 바꿔버림)
    size = 1
    for d in range(4):
        nx, ny = x + dx[d], y + dy[d]
        if 0 <= nx < n and 0 <= ny < n and board[nx][ny] == 1:
            size += dfs(nx, ny)
    return size

sizes = []
for i in range(n):
    for j in range(n):
        if board[i][j] == 1:
            sizes.append(dfs(i, j))

print(len(sizes))
print('\n'.join(map(str, sorted(sizes))))
```

> `setrecursionlimit` 안 쓰면 큰 입력에서 런타임 에러(RecursionError)
{: .prompt-warning }

## 시간복잡도 / 효율성

| 저장 방식 | 시간복잡도 |
| --- | --- |
| 인접 리스트 | O(V + E) |
| 인접 행렬 | O(V²) |
| N×M 격자 | O(N × M) |

모든 노드를 한 번씩, 모든 간선을 한 번씩(무방향은 두 번) 본다.
