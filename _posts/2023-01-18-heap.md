## 간단한 소개

계속 값이 들어오고 나가는데 **매번 제일 작은(큰) 값**을 꺼내야 할 때 쓴다.
매번 정렬하면 O(N log N)씩 걸리는데, 힙은 O(log N)이면 된다.
다익스트라에서 다시 나오니까 확실히 알아두기.

## 개념

- **우선순위 큐** : 들어온 순서가 아니라 우선순위가 높은 것부터 나가는 큐
- **힙** : 우선순위 큐를 구현하는 **완전 이진 트리**
  - 최소 힙 : 부모 ≤ 자식 → 루트가 최솟값
  - 최대 힙 : 부모 ≥ 자식 → 루트가 최댓값
- 파이썬 `heapq`는 **최소 힙**

## 원리

![최소 힙](/assets/img/posts/algorithm/heap.png){: width="480" }
_최소 힙 - 루트가 항상 최솟값_

```text
        1            ← 루트 = 최솟값
      /   \
     3     2
    / \   /
   7   4 5

리스트로는 [1, 3, 2, 7, 4, 5]
i번 노드의 자식 = 2i+1, 2i+2
```

- **넣을 때** : 맨 끝에 넣고 부모보다 작으면 위로 계속 교환 (O(log N))
- **뺄 때** : 루트 빼고, 맨 끝 값을 루트로 올린 뒤 자식이랑 비교하며 아래로 (O(log N))

트리 높이가 log N이라서 둘 다 O(log N).

## 코드

### 기본 사용

```python
import heapq

h = []
heapq.heappush(h, 5)
heapq.heappush(h, 1)
heapq.heappush(h, 3)
heapq.heappop(h)        # 1
h[0]                    # 최솟값 확인만

arr = [5, 1, 3]
heapq.heapify(arr)      # 리스트를 힙으로 O(N)
```

### 최대 힙 - 음수로 넣기

```python
heapq.heappush(h, -x)
max_val = -heapq.heappop(h)
```

### 기준이 여러 개면 튜플

```python
heapq.heappush(h, (abs(x), x))   # 절댓값 작은 순, 같으면 실제 값 작은 순
```

### 1927 최소 힙

```python
import sys, heapq
input = sys.stdin.readline

h = []
out = []
for _ in range(int(input())):
    x = int(input())
    if x == 0:
        out.append(heapq.heappop(h) if h else 0)
    else:
        heapq.heappush(h, x)
print('\n'.join(map(str, out)))
```

### 1715 카드 정렬하기 (작은 거 두 개씩 계속 합치기)

```python
import sys, heapq
input = sys.stdin.readline

n = int(input())
h = [int(input()) for _ in range(n)]
heapq.heapify(h)

total = 0
while len(h) > 1:
    a = heapq.heappop(h)
    b = heapq.heappop(h)
    total += a + b
    heapq.heappush(h, a + b)
print(total)
```

## 시간복잡도 / 효율성

| 연산 | 시간복잡도 |
| --- | --- |
| push | O(log N) |
| pop | O(log N) |
| 최솟값 확인 `h[0]` | O(1) |
| heapify | O(N) |

> "상위 K개", "매번 최소/최대 꺼내기", "작은 것끼리 합치기"가 보이면 힙
