## 간단한 소개

나중에 넣은 게 먼저 나오는 구조. 괄호 문제, "직전 값이랑 비교" 문제에서 자주 나온다.
DFS도 사실 스택으로 돌아간다.

## 개념

- **후입선출 (LIFO, Last In First Out)**
- 맨 위(top)에서만 넣고 뺀다.
- 파이썬은 그냥 **리스트**로 쓰면 된다.

## 원리

```text
push 1 → push 2 → push 3 → pop

 |   |     |   |     | 3 |     |   |
 |   |     | 2 |     | 2 |     | 2 |
 | 1 |     | 1 |     | 1 |     | 1 |
 └───┘     └───┘     └───┘     └───┘   → 3이 먼저 나옴
```

## 코드

### 기본 사용

```python
stack = []
stack.append(1)    # push
stack.append(2)
stack[-1]          # top 확인 → 2
stack.pop()        # pop → 2
if not stack:      # 비었는지
    ...
```

### 9012 괄호

```python
def is_vps(s):
    stack = []
    for c in s:
        if c == '(':
            stack.append(c)
        else:
            if not stack:      # 닫는 괄호인데 비어 있음
                return False
            stack.pop()
    return not stack           # 다 끝났는데 남아 있으면 False
```

`)`가 나왔는데 스택이 비어 있는 경우를 빼먹어서 한 번 틀렸다.

### 모노토닉 스택 - 17298 오큰수

"오른쪽에서 나보다 큰 첫 번째 수" 같은 문제. 이중 for문이면 O(N²)라서 시간초과.
스택에 **아직 답을 못 찾은 인덱스**를 쌓아두고, 큰 수가 나오면 한꺼번에 처리한다.

```python
n = int(input())
a = list(map(int, input().split()))
ans = [-1] * n
stack = []                       # 인덱스 저장

for i in range(n):
    while stack and a[stack[-1]] < a[i]:
        ans[stack.pop()] = a[i]
    stack.append(i)

print(*ans)
```

> 스택 안의 값이 항상 감소하는 상태로 유지돼서 "모노토닉(단조) 스택"이라고 부른다.
{: .prompt-info }

## 시간복잡도 / 효율성

| 연산 | 시간복잡도 |
| --- | --- |
| push (`append`) | O(1) |
| pop | O(1) |
| top 확인 (`[-1]`) | O(1) |

오큰수처럼 while이 for 안에 있어도, 각 원소는 한 번 들어가고 한 번 나오니까 전체 **O(N)**.
