## 간단한 소개

알고리즘보다는 **문제에 나온 규칙을 그대로 코드로 옮기는** 유형.
삼성 기출에 많이 나온다고 해서 정리. 어렵다기보다 실수가 많이 나오는 유형이다.

## 개념

- 정해진 규칙대로 상태를 바꿔가며 진행 (이동, 회전, 충돌 등)
- 자주 나오는 패턴
  - 2차원 격자에서 상하좌우 이동
  - 배열 회전
  - 달팽이 채우기
  - 시간에 따라 상태 변화 (뱀, 로봇 청소기)

## 원리

푸는 순서를 정해두니까 실수가 줄었다.

1. 문제 조건을 **번호 매겨서 정리** (종이에)
2. 상태를 뭘로 저장할지 정하기 (좌표, 방향, 보드)
3. 한 턴에 일어나는 일을 함수로 쪼개기
4. **예제 입력으로 손으로 한 번 돌려보기**

## 코드

### 방향 배열 (상하좌우)

```python
dx = [-1, 1, 0, 0]   # 상 하 좌 우 (행)
dy = [0, 0, -1, 1]   #            (열)

for d in range(4):
    nx, ny = x + dx[d], y + dy[d]
    if 0 <= nx < n and 0 <= ny < m:    # 범위 체크 필수
        ...
```

시계 방향 회전이 필요한 문제는 **북 동 남 서** 순서로 두면 편하다.

```python
dx = [-1, 0, 1, 0]   # 북 동 남 서
dy = [0, 1, 0, -1]

d = (d + 1) % 4      # 오른쪽으로 90도
d = (d + 3) % 4      # 왼쪽으로 90도
```

### 2차원 배열 회전

```python
# 시계 방향 90도
rotated = [list(row) for row in zip(*board[::-1])]

# 반시계 방향 90도
rotated = [list(row) for row in zip(*board)][::-1]
```

처음엔 이해가 안 돼서 작은 3x3 배열로 직접 찍어봤다.

```text
1 2 3        7 4 1
4 5 6   →    8 5 2
7 8 9        9 6 3
```

### 달팽이 채우기 (1913 달팽이)

막히면 방향을 바꾸는 방식.

```python
n = int(input())
board = [[0] * n for _ in range(n)]

dx = [1, 0, -1, 0]   # 하 우 상 좌
dy = [0, 1, 0, -1]
x = y = d = 0

for num in range(n * n, 0, -1):
    board[x][y] = num
    nx, ny = x + dx[d], y + dy[d]
    if not (0 <= nx < n and 0 <= ny < n) or board[nx][ny]:
        d = (d + 1) % 4                  # 벽이거나 이미 채웠으면 방향 전환
        nx, ny = x + dx[d], y + dy[d]
    x, y = nx, ny

for row in board:
    print(*row)
```

## 시간복잡도 / 효율성

- 대부분 **보드 크기 × 진행 횟수** 정도라서 시간보다는 정확성이 문제
- 보드가 N×N이고 K턴이면 O(N² × K)인 경우가 많다
