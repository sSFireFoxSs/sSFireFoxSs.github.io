## 간단한 소개

데이터를 순서대로 나열하는 것. 정렬 자체가 문제인 경우보다
**정렬해놓고 그리디/이분탐색/투포인터를 쓰는 경우**가 훨씬 많다.

## 개념

- 코테에서는 직접 구현할 일은 거의 없고 `sort()`, `sorted()` 쓰면 됨
- 대신 **key로 기준 정하는 법**은 꼭 알아야 한다
- 기본 정렬 알고리즘은 면접이나 시험용으로 개념만

## 원리

![병합 정렬](/assets/img/posts/algorithm/merge-sort.png){: width="560" }
_병합 정렬 과정_

| 정렬 | 방식 | 시간복잡도 |
| --- | --- | --- |
| 버블 | 옆이랑 비교해서 큰 걸 뒤로 계속 보냄 | O(N²) |
| 선택 | 남은 것 중 제일 작은 걸 찾아 앞으로 | O(N²) |
| 삽입 | 앞쪽 정렬된 부분에 알맞은 자리 찾아 끼움 | O(N²), 거의 정렬돼 있으면 O(N) |
| 병합 | 반으로 쪼개서 정렬한 뒤 합침 | O(N log N) |
| 퀵 | 기준(pivot)보다 작은 쪽 / 큰 쪽으로 나눔 | 평균 O(N log N), 최악 O(N²) |
| 계수 | 값의 개수를 세서 그대로 출력 | O(N + K), 값 범위 K가 작을 때만 |

```text
선택 정렬 예시
[5, 3, 1, 4]
[1, 3, 5, 4]   ← 1을 맨 앞으로
[1, 3, 5, 4]   ← 3은 이미 자리
[1, 3, 4, 5]   ← 4를 세 번째로
```

파이썬 기본 정렬은 **Tim Sort** (병합 + 삽입) 라서 O(N log N)이고, 같은 값끼리 원래 순서가 유지된다(안정 정렬).

## 코드

### 기본 사용

```python
arr.sort()                 # 원본 정렬
arr.sort(reverse=True)     # 내림차순
new = sorted(arr)          # 새 리스트 반환
```

### key로 기준 정하기

```python
# 11650 좌표 정렬 : x 오름차순, 같으면 y 오름차순
points.sort(key=lambda p: (p[0], p[1]))

# 1181 단어 정렬 : 길이 순, 같으면 사전 순 (중복 제거)
words = sorted(set(words), key=lambda w: (len(w), w))

# 점수 내림차순, 이름 오름차순
students.sort(key=lambda s: (-s[1], s[0]))
```

숫자는 `-` 붙이면 반대로 정렬된다. 이거 알고 나서 편해짐.

### 10814 나이순 정렬 (안정 정렬 활용)

나이가 같으면 **가입한 순서** 유지. 파이썬 정렬은 안정 정렬이라 나이만 기준으로 주면 끝.

```python
import sys
input = sys.stdin.readline

n = int(input())
members = [input().split() for _ in range(n)]
members.sort(key=lambda x: int(x[0]))
for age, name in members:
    print(age, name)
```

### 10989 수 정렬하기 3 (계수 정렬)

N이 1000만인데 메모리 8MB → 리스트에 다 담으면 메모리 초과. 숫자가 10000 이하라서 개수만 센다.

```python
import sys
input = sys.stdin.readline

n = int(input())
cnt = [0] * 10001
for _ in range(n):
    cnt[int(input())] += 1

for i in range(1, 10001):
    for _ in range(cnt[i]):
        print(i)
```

## 시간복잡도 / 효율성

- `sort()` / `sorted()` : **O(N log N)**
- N ≤ 100만 정도는 그냥 정렬해도 됨
- 값의 범위가 작고 N이 엄청 크면 계수 정렬
