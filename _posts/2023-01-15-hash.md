## 간단한 소개

"있는지 없는지", "몇 개인지"를 빠르게 알아야 할 때 쓰는 구조.
리스트로 `in` 하다가 시간초과 나면 거의 해시로 바꾸면 해결된다.

## 개념

- **해시 맵 (dict)** : 키 → 값 쌍으로 저장
- **해시 셋 (set)** : 키만 저장, 중복 자동 제거
- 키를 해시 함수로 숫자(주소)로 바꿔서 바로 찾아가기 때문에 검색이 **O(1)**

## 원리

```text
 key       hash(key)      저장 위치
"apple" ──▶   3     ──▶  [3] = 500
"banana" ─▶   7     ──▶  [7] = 300
```

리스트는 처음부터 하나씩 비교해야 하지만(O(N)), 해시는 계산해서 바로 위치를 찾는다.
대신 순서가 의미 없고, 키는 바뀌지 않는 값(숫자, 문자열, 튜플)만 가능하다.

## 코드

### dict 기본

```python
d = {}
d['apple'] = 3
d.get('banana', 0)        # 없으면 0 (KeyError 안 남)
'apple' in d              # O(1)
del d['apple']

for k, v in d.items():
    print(k, v)
```

### set 기본

```python
s = set([1, 2, 2, 3])     # {1, 2, 3}
s.add(4)
s.remove(1)
a & b                     # 교집합
a | b                     # 합집합
a - b                     # 차집합
```

### Counter / defaultdict

```python
from collections import Counter, defaultdict

cnt = Counter([1, 1, 2, 3, 3, 3])
cnt[3]                    # 3
cnt.most_common(1)        # [(3, 3)]

group = defaultdict(list)
group['fruit'].append('apple')   # 키 없어도 바로 append 가능
```

### 1764 듣보잡 (교집합)

```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
heard = set(input().strip() for _ in range(n))
seen = set(input().strip() for _ in range(m))

ans = sorted(heard & seen)
print(len(ans))
print('\n'.join(ans))
```

### 9375 패션왕 신해빈 (종류별 개수 세기)

```python
from collections import defaultdict

t = int(input())
for _ in range(t):
    n = int(input())
    cnt = defaultdict(int)
    for _ in range(n):
        name, kind = input().split()
        cnt[kind] += 1

    ans = 1
    for v in cnt.values():
        ans *= (v + 1)        # 안 입는 경우 +1
    print(ans - 1)            # 알몸 제외
```

## 시간복잡도 / 효율성

| 연산 | dict / set | list |
| --- | --- | --- |
| 검색 `x in` | **O(1)** | O(N) |
| 추가 | O(1) | O(1) |
| 삭제 | O(1) | O(N) |

> 메모리는 리스트보다 많이 쓴다. N이 작으면 그냥 리스트도 괜찮음.
